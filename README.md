## SZU 2026 最新版 LaTeX 硕士论文正文模板

本模板采用自文档化设计，模板的使用说明已嵌入正文。建议阅读：[master_pang.pdf](https://cao-wuhui.github.io/SZU_Latex_Master_Template/master_pang.pdf)。

### 快速开始

下载该文件 zip 导入到相关的 LaTeX 编辑工具即可，推荐使用 [Overleaf](https://cn.overleaf.com)，请注意更改编译器为 `XeLaTeX`。

本项目供深圳大学和兄弟学校免费试用。如发现任何问题，请提交 issue 反馈。如果已经有解决方案，可以提交 PR 贡献源代码。如果想加入维护团队以获得仓库写入权限，请联系：caoyixuan2019@email.szu.edu.cn。
